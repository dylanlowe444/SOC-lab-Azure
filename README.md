SOC-lab-Azure

*****Project Overview*****

This project demonstrates a cloud-based Security Operations Center (SOC) lab built in Microsoft Azure. The lab was created to gain hands-on experience with security monitoring, log collection, incident investigation, and threat detection using Microsoft Sentinel.


Technologies Used

- Microsoft Azure
- Microsoft Sentinel
- Log Analytics Workspace
- Virtual Network
- Data collection rule
- Windows Virtual Machine
- Kusto Query Language (KQL)
- Network Security Groups (NSGs)

Objectives

- Deploy a Windows VM in Azure
- Collect and analyze security logs
- Forward logs into Microsoft Sentinel
- Monitor authentication activity
- Investigate incidents and alerts
- Visualize attack activity

Skills Demonstrated

- SIEM Administration
- Security Monitoring
- Log Analysis
- Threat Detection
- Incident Response
- KQL Query Development
